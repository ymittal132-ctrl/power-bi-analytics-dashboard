# Power BI Sales Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze
sales performance, identify key trends, and present business insights through
clear and dynamic visualizations.

## Tools Used

- Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis

## Dashboard Features

- Interactive KPIs
- Sales performance analysis
- Trend analysis
- Interactive filters and slicers
- Data visualization
- Business insights
